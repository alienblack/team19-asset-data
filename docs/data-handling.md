# Data Handling

## Allowed in this repository

- Synthetic datasets created by the team.
- Public datasets, subject to their licence and a source citation.
- Literature-derived assumptions, clearly labelled as assumptions.
- Source code, tests, methodology notes and non-confidential results.

## Not allowed in this repository

- Confidential SA Power Networks data or extracts.
- Screenshots, recordings, meeting transcripts or client documents unless the
  client has explicitly approved this storage location.
- Credentials, access tokens, personal data or signed documents.

## Required experiment record

Each experiment must record its purpose, asset stream, data provenance, random
seed, attributes used, masking mechanism, train/test split, metrics, result
location, assumptions and limitations.
