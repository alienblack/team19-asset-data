05 / Interpretation and limitations

What the results support

Recovery depends on information that remains visible.

Compare field-level results with the original gap patterns and the configured hiding mechanism. Associations are descriptive; a successful run does not establish the cause of a field's errors.

A point fill can change the completed distribution.

Inspect the distribution charts and completed exports as well as MAE. Concentrating values near the centre can hide extremes or distort population counts.

Recorded errors are retained.

This workflow fills blanks and preserves recorded inputs. It does not repair a wrong value that is already present. Without a clean truth file, validation cannot identify those recording errors.

No automatic-acceptance claim is made.

These are point estimates with cross-validated reconstruction scores. Generic uncertainty calibration, record screening and production auto-fill thresholds are not fitted here. The separate Subteam A confidence study has a different protocol.

This is one configured condition.

There is no parameter tuning on evaluation scores. Change settings in a separate run to test another condition; do not interpret a single noise level as a measured noise sensitivity curve.
