# PGS219-260 checked synthetic demonstration outputs

These outputs were generated by the PGS219-259 demo entry point using the previously published benchmark implementation. They contain synthetic asset records and scored predictions.

- `live_default` uses nominal 30% gaps and plus or minus 5% measured jitter.
- `live_noise10` keeps the masks and changes the jitter amplitude to plus or minus 10%.
- Both use one spatial split, 1,500 training, 600 calibration and 600 test rows with fixed defaults.
- Large CSVs are gzip-compressed without changing their decompressed bytes.

From the shared repository root, independently check either saved execution.

```sh
python experiments/subteam_a_transformer_benchmark/scripts/verify_product_review.py experiments/subteam_a_transformer_benchmark/docs/product_review/evidence/live_default
```

The checker recomputes field errors, relative skill, tolerance agreement, numeric coverage and comparison summaries. It validates partitions, the hidden-cell ledger, recorded-value preservation and the GMM example's component contributions. Three focused tests confirm that the checked example passes and that tampered observations or fills are rejected.

The full tuned benchmark and the small demonstration have different scopes. Use the final report for the repeated results.
