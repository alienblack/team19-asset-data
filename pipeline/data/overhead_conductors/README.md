# Sample data (synthetic)

Every file in this folder is **synthetic**. It was generated by
`experiments/synthetic_data/generate_synthetic_data.py` (relationship-strength
profile `strength_100`, seed 219) from published, aggregate descriptions of an
overhead-conductor population. No record corresponds to a real asset and no
SA Power Networks data was used to produce it. See `docs/DATA_HANDLING.md` for
the rule on confidential data.

| File | Rows | What it is |
|---|---|---|
| `conductors_synthetic_complete.csv` | 10,000 | Complete reference: every model attribute observed. Used as truth in `experiments/model_comparison`. |
| `conductors_synthetic_masked.csv` | 10,000 | The complete file with 20% of every model attribute (and the linked `asset_age`) hidden independently at random (masking rule `MF01`, seed 219). The realistic starting point for imputation. |
| `conductors_synthetic_masked_metadata.json` | – | How the mask was generated. |
| `conductors_synthetic_dirty.csv` | 10,005 | The masked file with documented data-quality defects injected by `experiments/synthetic_data/make_dirty_sample.py` (label variants, whitespace, missing tokens, sentinel years, non-numeric distances, duplicate rows). The input of the example pipeline run. |
| `conductors_synthetic_dirty.defects.csv` | 436 | Every injected defect, so the cleaning log can be checked against it. |

Columns: `segment_id`, `feeder_id`, `installation_year`, `asset_age`,
`voltage_category`, `location_group`, `corrosion_zone`, `distance_to_sea_km`,
`material`, `covering`, `length_km`, `data_status`, `record_version`.
`data_status` is `Synthetic` in every row.

A property of this generator worth knowing before reading any accuracy
figure: `installation_year` is drawn first and only influences the other
attributes at a coarse era level, so it is close to unpredictable from the
seven model attributes (a model fitted on the complete data reaches about the
same error as the median). `material` carries a weak signal. See
`docs/LIMITATIONS.md`.

Regenerate:

```bash
python experiments/synthetic_data/generate_synthetic_data.py --strength-profile strength_100
python experiments/synthetic_data/run_masking.py --rules MF01 --input experiments/synthetic_data/outputs/synthetic/strength_100/material_model_ready_data.csv
python experiments/synthetic_data/make_dirty_sample.py --input data/sample/conductors_synthetic_masked.csv --output data/sample/conductors_synthetic_dirty.csv
```
